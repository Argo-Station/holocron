# Credits

Every image, icon and media file in this repository is listed here with where it came from. The export that
builds this repository refuses any media file this page doesn't name.

## Made for this project

- `public/Assets/*.png`, `public/Assets/narrative/*.png`, `public/Assets/background/*.png`,
  `public/Assets/career/*.png`, `public/Assets/chars/*.png`, `public/Assets/map/*.png`,
  `public/Assets/spec/*.png`, `public/Assets/species/*.png`, `public/Assets/terminal/*.png`,
  `public/Assets/weapons/*.png`: interface art made for Project Holocron with AI image tools, ChatGPT among them.
  Some files carry the tool's own content-credentials (C2PA) note, which is left in place.
- `public/icons/*`: the app icons.
- `art/washes/`: the species backdrop washes, generated by a script. The colour model (fifteen named colours,
  one phrase per species) follows the Complete Species Guide's own background generator, by Yaccarus with
  mrdollar11 and thedearth2. The images are generated here, and none of the Guide's art is copied.
- `art/wear.webp`: the paper texture, generated by a script.
- `guide/*.png`: the pictures in `GUIDE.md`, rendered from this project's own drawings. The Mac and Windows windows
  in them are drawn for reference and are not Apple's or Microsoft's images.

These files are under the same licence as the code (MIT, see `LICENSE`).
